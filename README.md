# Akmal Sweets — Website

A rebuild of the website for **Akmal Sweet Center & Fastfood**
(akmalsweets.com) — a Pakistani sweets shop and fast-food restaurant in
Frankfurt am Main, family-run since 1974.

## Pages

| Page | File | Original page |
|------|------|---------------|
| Home | `index.html` | akmalsweets.com |
| Sweets · Süßigkeiten | `sweets.html` | akmalsweets.com/sweets |
| Menu · Speisekarte | `menu.html` | akmalsweets.com/menus |
| Contact · Kontakt | `contact.html` | akmalsweets.com/contact |

## Tech

- Plain HTML + CSS + a small bit of vanilla JS — no build step, no frameworks,
  no external dependencies.
- Fully responsive (mobile nav toggle included).
- Bilingual German/English, matching the original site's style.
- Open `index.html` in a browser, or serve with any static server
  (`python3 -m http.server`). Works out of the box with GitHub Pages.

## Data sources & things to verify

The original site blocks automated access, so content was reconstructed from
its search-engine index and public listings. The following facts are sourced:

- **Address:** Elbestraße 22, 60329 Frankfurt am Main (Bahnhofsviertel)
- **Phone:** (069) 23 31 80
- **Hours:** Mon–Sat 11:15–18:00, Sunday closed
- **Established:** 1974
- **Sweets:** Gulab Jamun, Ras Gulla, Ras Malai, Cham Cham, Ladoo,
  Kaju Barfi, Barfi, Jalebi; mixed 1 kg box ≈ €9–11
- **Food:** lamb curry, chicken curry, bhindi (okra), daal, chana,
  palak paneer, samosas, samosa chaat, pakora, dahi pakora — mains served
  with 2 roti or rice; many dishes vegetarian and/or lactose-free
- **Drinks:** mango lassi, lassi, soft drinks

**Please verify before going live:** individual item prices (not published
online), the exact daily selection, product photos, and any legal pages
(Impressum/Datenschutz) required for a German business website.
